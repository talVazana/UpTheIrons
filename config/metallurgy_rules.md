# Metallurgical & Technical Accuracy Rules

## Strict Technical Guardrails
1. **Never Hallucinate Chemistry:** AI and ingestion filters must NEVER invent alloying element percentages (e.g. Carbon %, Chromium %, Vanadium %).
2. **Never Guess Thermal Data:** Heat treatment recipes (normalizing, austenitizing, annealing, tempering) must be derived from verified steel manufacturer data sheets (e.g. Crucible, Bohler, AISI/SAE).
3. **Never Guess Hardness:** Rockwell C (HRC) values must represent measured metallurgical ranges from standardized quench/temper curves, not arbitrary estimates.
4. **Primary References Required:** Any guide specifying critical temperatures must cite an authoritative metallurgical source or standard industry practice.
5. **Scrap Steel Disclaimers:** When working with mystery steels (leaf springs, coil springs, files), guides must mandate test quenches and warn that chemical composition and previous stress history are unknown.
