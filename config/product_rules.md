# Product & Tool Evaluation Rules

## Commercial Neutrality
1. **Zero Ranking Distortion:** Products are listed and sorted strictly by objective metrics (price, beginner suitability, date added). Commercial affiliate status never boosts priority or sorting order.
2. **Transparent Affiliate Disclosure:** Any link containing an affiliate code must explicitly display an affiliate badge and disclaimer.
3. **Price Freshness:** Display the timestamp of when a price was recorded. Never present stale historical prices as live quotes.

## Mandatory Honest Assessment
Every tool or hardware entry in the vault must include:
1. **Pros:** Genuine technical advantages in an amateur workshop context.
2. **Cons:** Honest limitations (e.g. cast iron vs cast steel rebound, thermal mass limitations, motor duty cycles).
3. **Beginner Suitability:** Explicit boolean indicating whether a beginner should invest in this item or if simpler, cheaper DIY options exist.
4. **Alternatives:** At least one lower-cost DIY or scrap substitute (e.g. railroad track anvil alternative to a $1,200 cast steel anvil).
